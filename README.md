
# COVID-19 Vaccination and Epidemiological Indicators

## About the Project

This project was developed as part of the Introduction to Statistics course at the Faculty of Mathematics, University of Belgrade.

It examines changes in COVID-19 epidemiological indicators in Australia, the United Kingdom, and Russia before and after reaching 50% full vaccination coverage.

## Authors

- Staša Rakić
- Dunja Roža

## Methodology

Using data from Our World in Data, we analyzed 180-day periods before and after the vaccination threshold.

The analysis includes:
- Descriptive statistics
- Wilcoxon rank-sum tests
- Two-proportion tests
- Boxplots and bar charts

## Technologies

- R
- Statistical analysis
- Data visualization

## Key Findings

The Wilcoxon tests indicated statistically significant differences in the United Kingdom and Russia, but not in Australia at the 5% significance level.

The proportion tests indicated lower reported death-to-case proportions after the threshold in all three countries.

These observational results do not establish a causal relationship between vaccination and mortality.
